Privacy

Privacy

This is a static website. Shader Protocol does not run accounts, forms, or its own analytics on these pages.

What this site collects

The pages do not ask for a name, an email address, a wallet, or a cookie banner of our own. We do not add a third-party tracker.

The site is hosted on GitHub Pages. GitHub, as the host, may keep standard server logs such as IP address, user agent, and the URL requested. That is the hosting log, not a dataset this project collects on top.

Links away from the site

Links to GitHub, including the repository and private vulnerability reports, are governed by GitHub once you leave these pages.

The software is separate

Wallets, RPC providers, and testnets you use while trying the code are not this website. Those operators see whatever their own systems log. Read the security note before you run anything.

Shader Protocol. Not audited. Devnet/testnet only. No token. No mainnet.
