Privacy

This static site does not run an account system. The testnet app talks to your wallet in the browser. Notes you export stay in your browser unless you download them.

A wallet connection reveals your address to the page and to the chain you use. A deposit is public. A shielded spend publishes a nullifier, two commitments, amounts, and a proof. It does not publish the spending key. The DarkPool operator path in the repository is different: that process decrypts orders and learns spending keys.

Loading snarkjs or a wallet library from a CDN sends your IP address to that CDN. The ceremony page does this. The marketing pages use fonts stored on this site.

There is no analytics pixel in these pages. GitHub Pages, which may host the site, has its own logs.

To report a vulnerability, use GitHub private vulnerability reporting.
