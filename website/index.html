    02 // Premise

    Public ledgers leak too much.

    Blockchains made it possible to verify every transfer without trusting a bank. The price is that everything is visible to everyone, forever. Shade keeps the verifiability and drops the exposure.

    Balances

    Balances are public

    Link one wallet to you, through a withdrawal, a name or a single payment, and anyone can see what you hold and everything you've done with it.

    Orders

    Orders leak early

    A pending trade reveals its size, direction and limit price. Searchers see it and act first: sandwich attacks, worse fills, higher slippage.

    Strategy

    Strategies leak

    Supplier payments, fund rebalancing and DAO payroll expose information that would stay confidential in traditional finance.

    05 // Roadmap

    Ship primitives, not buzzwords.

    Each phase begins only when the previous one is genuinely finished.

    1. Phase 0 · Now

      Devnet

      Solana devnet deployment, SDK, test suite and CI. Development trusted setup only. Expect breaking changes and resets.

    2. Phase 1

      Testnets + hardening

      NEAR testnet and other adapters; fuzzing, internal review, public bug reports.

    3. Phase 2

      Independent audit

      Third-party review of circuits, cryptography, contracts and SDK, with findings published.

    4. Phase 3

      Setup ceremony

      Public multi-party ceremony for production Groth16 keys, with published transcripts.

    5. Phase 4

      Mainnet (conditional)

      Only after phases 2 and 3, with conservative deposit limits and a staged rollout.

    No dates are promised. Roadmap items describe intentions, not commitments.

    Security
    Threat model
    Funds safety rests on cryptography and on-chain proof checks, not an operator. The dark-pool matcher is trusted for order privacy, not funds.
    Key mgmt
    Separate spend and view keys; viewing keys can be scoped to a time window and can't spend.
    Audits
    Not yet audited. An independent audit is a required phase before any mainnet.
    Bug bounty
    None yet. Report vulnerabilities privately: see the security doc.
