From source

There is no published package yet. Clone the repository, which is still named shade-protocol:

github.com/Chenz0-13/shade-protocol

The client class is ShadeClient. That identifier has not been renamed. Methods you will see in src/sdk/ include init, generateKeys, mintNote, shieldedTransfer, and sealDarkOrder. Signatures can change. Read the source rather than an old snippet.

Chain adapters refuse mainnet RPC targets. Solana, Robinhood Chain testnet (46630), Kinetiq Elysium testnet (99801), and NEAR testnet are in development and are not deployed. Canton submission throws. It does not return a fake transaction id.

generateGroth16KycProof throws. Do not wrap it and tell a user a proof was created.

Security reports go to private vulnerability reporting, not a public issue.
