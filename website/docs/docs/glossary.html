Glossary

Commitment. A Poseidon hash of a note opening. The value is not written in the clear.

Nullifier. A value bound to the commitment and the leaf index. The pool stores it to reject a second spend.

extDataHash. A public input binding the recipient, relayer, fee, chain, and pool. The contract recomputes it.

Root history. Recent Merkle roots kept by a pool. A proof must cite one of them.

Canonical field inputs. Public inputs encoded as field elements in a fixed order.

Stealth address. A one-time secp256k1 address. The view key recognizes it. The view key does not spend.

Regulator key. An issuer-signed secp256k1 encryption key with a scope.

ShadeClient. The current class name of the TypeScript client. The product name is Shader Protocol. The class name has not changed.

Dark pool. The operator matcher in this repository. The operator can read sealed orders. It is a devnet tool.

Canton attestation. A 2-of-N record by named attestors. Not a Groth16 verifier.

KYC proof. Not implemented. Planned at most.

Devnet / testnet. Networks with valueless test assets. This software targets those only.

Guarded beta. A possible later step with caps, after a ceremony and an independent audit. Not available now. Not a mainnet.
