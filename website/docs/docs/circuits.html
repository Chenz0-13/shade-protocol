Circuits

shielded_transfer.circom is the devnet transfer. It checks:

  • Poseidon Merkle membership of the input note.
  • The Poseidon commitment opening.
  • The nullifier bound to the commitment and the leaf index.
  • Range checks and asset equality.
  • Value conservation: value in = value out 1 + value out 2 + fee.
  • extDataHash over the recipient, relayer, fee, chain, and pool.

Public inputs are the canonical field elements: root, nullifier, two output commitments, fee, and extDataHash.

The circuit setup command compiles this circuit and runs a single-party Groth16 setup. Those keys are for tests and devnet experiments only. There is no multi-party ceremony yet.

What is not in the circuit

There is no KYC circuit. generateGroth16KycProof throws. Zero-knowledge KYC proofs are planned at most. Disclosure receipts are in development and are not enforced by this circuit.

Do not treat a missing measurement as a benchmark. This page does not publish constraint counts or proving times.
