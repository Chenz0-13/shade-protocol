Dark pool

The dark pool in this repository is an operator matcher for devnet tests. It is not a public order book, and it is not a promise about front-running on a public mempool.

What the operator sees

Orders are sealed to the operator view key. The operator opens them, checks the escrow note, and builds two shielded-transfer proofs for each side: a payment and change. The operator learns the openings it needs for that work. Do not treat this class as custody for anyone else's funds.

Matching rules in this build

  • Buys match only sells.
  • Price ranges have to overlap.
  • Each order is used once.
  • Nullifiers are marked spent only after the proofs verify in this devnet class.
  • The execution price is the low end of the overlapping range.

A sell escrows its base amount. A buy escrows amount * maxPrice of the quote asset.

This page does not claim that on-chain checks replace the operator, and it does not claim the matcher is trusted only for privacy. The operator can read the orders. Settlement still uses the shielded-transfer circuit described in circuits.
